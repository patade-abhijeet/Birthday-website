# Audio Instructions

To enable background music for Snehal's birthday website:

1. Place your chosen romantic audio file here as `birthday-music.mp3`.
   - File path: `public/audio/birthday-music.mp3`
2. Recommended audio style:
   - Soft acoustic guitar, gentle piano, or an instrumental melody that holds special meaning to both of you.
3. If no file is present, the website still functions flawlessly without any errors.
